# NOOTS (National Once-Only Technical System): research notes, no pre-run

Surveyed for version 0.3.0 on 20 November 2026 under decision D3 (TECH_NOTES.md): a pre-run is bundled only where public sources name, for the critical building blocks of most layers, who makes and who runs them.

## What it is

NOOTS is the IT infrastructure of the register modernisation, for the automatic retrieval of register data in applications. It is still being built: the NOOTS state treaty is ratified nationwide, and the IT-Planungsrat decides on the start of operations.

## Why there is no pre-run

The public sources found name the Bundesverwaltungsamt as the operator but no maker of any building block, no hosting and no software. A pre-run would record one operator and gaps in every layer, which says more about the state of the sources than about NOOTS. Once NOOTS is in operation and its building blocks are documented, a Live run can assess it.

Live mode accepts this entry like any other service; its run starts from the sources below.
